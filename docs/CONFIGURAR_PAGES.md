# Configurar GitHub Pages

1. Abra o repositório `CRJCARIACICA/educadoresplanejamento`.
2. Acesse **Settings**.
3. No menu lateral, abra **Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`.
6. Clique em **Save**.
7. Aguarde a conclusão do processo de publicação.
8. Use `index.html` para o aplicativo e `sync.html` para trabalhar com sincronização entre dispositivos.

O site publicado é público. Não inclua dados operacionais no repositório usado pelo Pages.
