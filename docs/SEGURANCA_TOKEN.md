# Segurança do token

- Use token fine-grained.
- Restrinja o token ao repositório privado de dados.
- Conceda somente `Contents: Read and write`.
- Não inclua o token no HTML, JavaScript, README, backup ou captura de tela.
- Digite o token apenas no portal `sync.html`.
- Feche a aba ao terminar para apagar o token da sessão.
- Revogue e gere outro token se houver suspeita de exposição.
