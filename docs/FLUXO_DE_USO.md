# Fluxo operacional recomendado

## Antes de começar

1. Abra `sync.html`.
2. Informe o repositório privado, branch, caminho e token.
3. Clique em **Baixar do GitHub**.
4. Aguarde a restauração e o recarregamento do aplicativo.

## Durante o trabalho

- Registre normalmente no aplicativo.
- Gere documentos e relatórios quando necessário.
- Faça cópias JSON locais em marcos importantes.

## Ao terminar

1. Volte ao painel de sincronização.
2. Clique em **Enviar para o GitHub**.
3. Confirme a mensagem de sucesso.
4. Feche a aba para apagar o token da sessão.

## Regra contra perda de dados

Nunca edite em dois dispositivos ao mesmo tempo. O último envio substitui a versão remota. Use o histórico de commits do repositório privado para recuperar versões anteriores.
