# Privacidade e proteção de dados

O repositório publicado pelo GitHub Pages deve conter somente código, estilos, documentação e recursos institucionais autorizados.

Não publicar no repositório público:

- nomes e contatos de jovens;
- CPF, endereço ou documentos;
- listas de presença preenchidas;
- fotografias e vídeos identificáveis sem tratamento adequado;
- formulários de acompanhamento, PVida ou PTrampo preenchidos;
- avaliações individuais;
- relatórios com informações pessoais ou sensíveis.

O backup operacional deve permanecer em repositório privado, com acesso restrito e token limitado ao mínimo necessário.
