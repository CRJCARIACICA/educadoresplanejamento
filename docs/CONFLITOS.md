# Prevenção de conflitos

A solução sem banco de dados não oferece edição simultânea nem mesclagem automática.

Procedimento obrigatório:

1. baixar o backup remoto antes de editar;
2. trabalhar em apenas um dispositivo por vez;
3. enviar o backup ao terminar;
4. verificar a mensagem de sucesso;
5. usar o histórico do repositório privado se uma versão anterior precisar ser recuperada.
