# Como atualizar o aplicativo

1. Baixe a versão HTML mais recente.
2. Renomeie o arquivo para `index.html`.
3. No repositório `CRJCARIACICA/educadoresplanejamento`, abra o arquivo `index.html`.
4. Clique no ícone de edição ou use **Add file > Upload files**.
5. Substitua o arquivo antigo.
6. Registre uma mensagem de commit clara, por exemplo: `Atualiza aplicativo com calendário A4 e anexos Word`.
7. Aguarde a nova publicação do GitHub Pages.

O portal `sync.html` permanece separado e continua acessando o LocalStorage do mesmo domínio.
